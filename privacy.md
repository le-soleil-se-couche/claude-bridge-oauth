# Claude-bridge Privacy Policy

Claude-bridge is a personal file management tool.

It accesses Google Drive files with the account
owner's authorization to download, process, and
upload files.

Files may be processed in the Anthropic Claude Code
cloud environment and stored in Google Drive.

Google Drive data is not sold or used for advertising.

Access can be revoked in Google Account settings.
